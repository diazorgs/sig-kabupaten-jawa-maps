Sumber: https://github.com/yusufsyaifudin/wilayah-indonesia
Berkas: data/list_of_area/regencies.json
Diakses: 5 Oktober 2026
Lisensi sumber: lihat odbl-10.md pada repositori sumber (Open Database License). Pertahankan atribusi dan ikuti ketentuan lisensinya ketika membagikan data turunan.

Enam CSV berisi 119 kabupaten/kota sesuai data sumber. Nilai koordinat dan nama dipertahankan; belum ada koreksi geografis yang diklaim. Berkas ini hasil konversi dataset publik, bukan hasil ekspor dari Google My Maps milik praktikan.

Pemeriksaan: ID unik; seluruh kolom terisi; latitude dan longitude numerik dalam rentang global; latitude negatif; longitude 100-120. Pemeriksaan ini belum memvalidasi lokasi setiap titik terhadap batas wilayah.

Impor CSV ke enam layer Google My Maps. Pilih latitude dan longitude untuk lokasi, name untuk judul. Verifikasi titik, catat perubahan, lalu ekspor CSV hasil akhir. Untuk unggahan GitHub, unggah enam CSV dan README ini.

Jumlah: Jawa Barat 27; DKI Jakarta + Kepulauan Seribu 6; Banten 8; Jawa Tengah 35; DI Yogyakarta 5; Jawa Timur 38.
